## Version A: Recommended Standard Resume Entry (Detailed)

### **RiskWise — FinTech Credit Risk Scoring & Loan Default Predictor**
**Technologies:** Python, Django, MySQL, Scikit-learn, Pandas, Power BI, Bootstrap 5, Chart.js, Git

**Summary:**  
Architected an end-to-end credit risk evaluation platform that automates loan underwriting assessments by predicting borrower default probabilities and computing custom credit risk scores (300–900). Built with a Django backend, MySQL database persistence, and an integrated Scikit-learn machine learning pipeline.

**Key Contributions & Highlights:**
- **Full-Stack Web Architecture**: Developed a responsive web application featuring custom email authentication, borrower self-service portals, credit application history, and an administrative analytics hub with live Chart.js portfolio visuals.
- **Machine Learning Pipeline**: Cleaned, transformed, and engineered features (loan-to-income, interest-to-income) across 32,000+ loan records using Scikit-learn's `ColumnTransformer`; trained a tuned Random Forest classifier achieving **0.935 ROC-AUC** and **93.5% accuracy**.
- **Relational Persistence & Business Logic**: Implemented atomic database transactions in MySQL linking loan applications to prediction results, enforcing borrower isolation and secure role-based access control.
- **Automated Verification**: Authored a comprehensive 18-test automated Django test suite validating public routing, authentication flows, form sanitization, prediction persistence, and error handling with a 100% pass rate.
- **Power BI Portfolio Analytics**: Designed a star-schema reporting model and authored validated DAX measures (`DIVIDE`, count aggregations) across 200+ benchmarked loan records for executive risk segmentation across loan grades, income tiers, and age brackets.

## Version C: Short Portfolio / LinkedIn Project Description

**RiskWise — Credit Risk Assessment & Underwriting Platform**  
RiskWise is an intelligent credit risk evaluation system designed to assist lending institutions in predicting borrower default risk. Built using Django, MySQL, and Scikit-learn, the platform analyzes borrower financial attributes to calculate statistical default probabilities and calibrated risk scores. It includes secure borrower portals, a custom administrative analytics dashboard, an automated 18-test validation suite, and a multi-page Power BI portfolio reporting model.
