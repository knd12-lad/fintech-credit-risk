# Power BI Data Ingestion: MySQL Direct Connector & CSV Fallback Guide

This guide describes how to connect Power BI Desktop to the RiskWise application data.

---

## Method 1: Direct MySQL Connector (Preferred for Live Refresh)

### 1. Prerequisites
- **MySQL Connector/NET**: Version 8.0 or 8.1 installed on Windows (available from Oracle MySQL official site).
- **Network Access**: MySQL running on `localhost:3306` (or configured database server host).

### 2. Connection Steps
1. In **Power BI Desktop**, click **Home -> Get Data -> More... -> Database -> MySQL Database**.
2. Click **Connect**.
3. **Server**: Enter `127.0.0.1:3306` (or `localhost`).
4. **Database**: Enter the database name from your `.env` file (e.g., `fintech_credit_risk` or `credit_risk_db`).
5. **Data Connectivity mode**: Select **Import** (recommended for DAX calculations and offline dashboards).
6. Under **SQL Statement** (optional, recommended for consolidated view):
   ```sql
   SELECT 
       app.id AS application_id,
       CASE 
           WHEN app.full_name LIKE 'Demo Applicant%' THEN app.full_name
           ELSE CONCAT('User #', app.user_id)
       END AS applicant_label,
       CASE 
           WHEN app.full_name LIKE 'Demo Applicant%' THEN 'Demo'
           ELSE 'Real'
       END AS is_demo,
       app.age,
       app.annual_income,
       app.employment_length,
       app.home_ownership,
       app.loan_grade,
       app.loan_amount,
       app.interest_rate,
       app.previous_default,
       app.credit_history_length,
       lt.code AS loan_intent_code,
       lt.name AS loan_intent_name,
       pred.default_probability,
       pred.credit_score,
       pred.risk_level,
       pred.predicted_status AS predicted_default,
       app.created_at
   FROM risk_app_loanapplication app
   LEFT JOIN risk_app_prediction pred ON app.id = pred.application_id
   LEFT JOIN risk_app_loantype lt ON app.loan_type_id = lt.id;
   ```
7. Click **OK**.
8. In the Credentials dialog:
   - Select **Database** on the left menu.
   - Enter your MySQL username and password (never share or commit these credentials).
   - Click **Connect**.

## Method 2: CSV Data Fallback (Universal & Standalone)

If the MySQL Connector/NET is not installed, or permissions prevent direct database connection:

### 1. Data File
Use the automated, sanitized CSV export generated by RiskWise:
```
c:\fintech-credit-risk\powerbi\data\riskwise_powerbi_dataset.csv
```

### 2. Properties
- Contains **202 validated records** (200 demo records + 2 live user applications).
- Completely stripped of sensitive PII, passwords, and tokens.
- Includes pre-calculated age groups (`18-25`, `26-35`, `36-50`, `51+`) and income tiers (`< $25k` to `> $100k`).

### 3. Ingestion Procedure
1. In **Power BI Desktop**, click **Get Data -> Text/CSV**.
2. Browse to `c:\fintech-credit-risk\powerbi\data\riskwise_powerbi_dataset.csv`.
3. Power BI will detect column headers and data types automatically.
4. Click **Load**.

### 4. Updating the Dataset on Future Runs
Whenever new predictions are generated in RiskWise, re-run:
```powershell
python -c "import os, django, pandas as pd; os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'config.settings'); django.setup(); from risk_app.models import LoanApplication; rows = [...]; pd.DataFrame(rows).to_csv('powerbi/data/riskwise_powerbi_dataset.csv', index=False)"
```
Then click **Refresh** in Power BI Desktop.
